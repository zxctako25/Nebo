##  О проекте

**Nebo** — это прокси-ядро для Minecraft, написанное на **Rust**.
Ядро построено на базе версии **1.16.5** и поддерживает клиенты и серверы
от **1.16.5 до 1.21.11**.

Идея проекта: один лёгкий и быстрый прокси, который объединяет разные версии игры
и не требует от игроков подбирать нужную версию клиента.

##  Возможности

-  Написан на Rust, быстрый и экономный по памяти
-  Поддержка версий **1.16.5 – 1.21.11**
-  Прокси-ядро на базе протокола 1.16.5
-  *(остальное в разработке, см. [Roadmap](#-roadmap))*

## Установка и сборка

### Требования

- [Rust](https://www.rust-lang.org/tools/install) (stable)
- Git

### Сборка из исходников

```bash
git clone https://github.com/zxctako25/nebo.git
cd nebo
cargo build --release
```

Готовый бинарник появится в `target/release/`.

## Запуск

```bash
cargo run --release
```

## Известные проблемы

Проект в стадии тестирования, поэтому возможны:

- вылеты и разрывы соединения на разных версиях;
- проблемы совместимости на отдельных версиях;
- неполная поддержка некоторых пакетов.

Список багов ведётся в [Issues](../../issues).
